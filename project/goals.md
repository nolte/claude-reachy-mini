# Vision

`claude-reachy-mini` is the nolte portfolio's Claude Code plugin for Reachy Mini
robot development. It bundles skills and agents for building Reachy Mini apps —
dance-to-music behaviours and Home Assistant integration — so the operator builds
them with consistent, spec-grounded tooling. It owns the
Reachy-Mini-development skill and agent set in the portfolio.

## Outcomes

- **O-1** — the plugin author, dogfooding in this repository, builds Reachy Mini
  behaviours and Home Assistant integration with consistent, spec-grounded skills
  and agents. _(audience: Plugin-Autor beim Dogfooding in diesem Repo (nolte))_
- **O-2** — later public users in the Reachy Mini hobby and maker community adopt
  the same skills and agents through the Claude Code plugin marketplace.
  _(audience: Spätere öffentliche Nutzer (Reachy-Mini-Hobby- und Maker-Community))_
